# 几何数据流：

## 一、定义

**一棵有向无环图（DAG）上，两种值沿边流动、按拉取方式求值的计算模型**：

**1. 图与端口**
节点树 G=(V,E)。节点 v 是**纯函数**（无副作用、不修改输入）；socket 是带类型的端口，有方向（输入/输出）。一条边 = 上游输出 socket → 下游输入 socket，**类型必须可接受**（float↔vector 等有隐式转换，Geometry 不自动转成别的）。

**2. 两种值**

|      | **Geometry 值**                                                                         | **Field 值**                                             |
| ---- | -------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 类型   | `NodeSocketGeometry`                                                                   | Float / Int / Bool / Vector / Color / Rotation / Matrix |
| 语义   | 一个**组件化几何集合** GeometrySet = {Mesh, PointCloud, Curve, Volume, Instances, GreasePencil} | 一个**惰性函数** f(元素上下文, 属性) → 标量/矢量/…                       |
| 可变性  | **不可变**：节点不修改输入，只产出新值                                                                  | 无状态：不在节点处求值                                             |
| 求值次数 | 每个节点求值**一次**                                                                           | 在**消费它的节点**的目标域上**逐元素**求值                               |
| 能改什么 | 拓扑、结构、几何资产本身                                                                           | 已有元素的属性（位置/半径/材质索引/自定义属性）                               |

常量是 field 的退化情形：任何 field 输入都可以接一个数字，等价于“处处返回该常数的零元函数”，会被广播到所有元素。

**3. 求值方向：拉取（pull-based）**
从 **Group Output** 反向拉取。没有被输出依赖的分支**不求值**。所以“前面给数值”之所以能影响结果，是因为那个值处在从输出可达的子图里。

**4. 两个正交维度**

- **结构维**（由 Geometry 边承载）：增删面、切、焊、细分、布尔、实例化/实化。**只有 Geometry socket 能承载拓扑变化。**
- **数值维**（由 Field 边承载）：每个 Point / Edge / Face / Corner 的属性。**Field 只能改“已有元素长什么样”，不能创建或删除元素。**

Geometry：它们本质仍是“吃一个 Geometry，吐一个新 Geometry”，只是内部用 field 决定怎么改。

**5. 域（domain）**
Point / Edge / Face / Corner / Spline / Instance / Layer。同一个 field 接给不同域会得到不同结果；域不匹配时按 Blender 的插值/广播规则转换。**判断一个 field 对不对，必须同时说清“在哪个域上求值”。**

**6. 对物体的最终作用**
= 把输入 GeometrySet 沿 DAG **逐节点重写成新值**，最后替换修改器的求值结果。没有增量修改、没有原地写。

**边界**：域只能决定“这个点挪到哪 / 多大 / 什么颜色”，**不能把零件切成两半、不能把两个零件粘起来、不能凭空多出一个面**。所有改“形状结构”的活，必须由 Geometry 来干。

**几何流决定“东西是什么形状”，field 决定“每个点上的数字是多少”。**
