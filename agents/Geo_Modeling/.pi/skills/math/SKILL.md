# 数学模型

## 第二步：逐现象翻译，建立数学模型
**目标**：把视觉模型中的每个现象，翻译成数学定义、公式和算法链。
1. **切分现象。** 把视觉模型拆成若干「可见变化单元」。每个单元只描述一件事，例如「主枝向上延伸」「侧枝在固定间隔出现」「末梢越往上越细」。
2. **逐现象翻译。** 对每个单元，回答五个问题：
   - 几何上是什么？（点、线、面、体、实例）
   - 用什么量描述？（位置、方向、长度、密度、半径、时间、随机量……）
   - 这个量怎么产生？（公式、分布、插值、噪声、选择、变换、累积）
   - 它依赖什么？（上游几何、参数、时间、随机种子）
   - 它输出什么，交给下一步的谁？
3. **连成算法链。** 按因果顺序把各现象接起来，写清每一步的输入和输出。
4. **给参数物理意义。** 每个参数都要说清「调大/调小会看到什么」。公式要能对应到具体现象，不能是通用模板。
5. **双向校验。** 回到视觉模型，确认每个可见变化都有数学来源；再回到算法链，确认每个算法都产生了某条可见变化。
6. **收束成数学模型。** 输出：现象到数学定义的映射、算法链、关键公式、参数及其视觉影响。

**产出**：一套只属于当前需求的数学模型，而不是一份通用算法目录。

## 例子
```text
输入：一个封闭、流形、法线朝外的实体网格 M ⊂ R³；片数 N，默认 30–50。
输出：N 块（非凸物体可能更多）互不重叠的封闭块；拼回去等于 M；块与块之间只有 1–2 mm 的展示错位，不散落。

一、种子与沃洛诺伊
在 M 内部按体密度 ρ 采样 N 颗种子 S = {s_1, ..., s_N}。第 i 块定义为
V_i = { x ∈ M | ||x - s_i|| ≤ ||x - s_j||, 对所有 j ≠ i }。
也就是说，V_i 是 M 中离 s_i 最近的那部分。默认物体是凸的或接近凸的，此时每块内部恰好一颗种子；非凸物体见第六节。

二、一刀一刀与沃洛诺伊的等价关系
任意两颗相邻种子 i、j 的垂直平分面是
H_ij = { x | (x - (s_i + s_j)/2) · (s_j - s_i) = 0 }。
靠 s_i 一侧的半空间是
H_ij^- = { x | (x - (s_i + s_j)/2) · (s_j - s_i) ≤ 0 }。
于是
V_i = M ∩ ⋂_{j≠i} H_ij^-。
每一刀对应一个切面 H_ij：对第 i 块保留 H_ij^- 一侧，对第 j 块保留另一侧。把所有相邻种子之间的切面都加完，V_i 就是 M 被这些半空间共同裁出来的部分。因此，刀的先后顺序只影响中间形态，不影响最终划分；最终一定是同一个沃洛诺伊划分。

实现上把“计算”和“演示”分开：
- 计算：逐块裁剪，直接得到最终的 V_i，保证严格是沃洛诺伊。
- 演示：再按某一顺序播放切面 H_k、切痕 C_k 和错位 d_i(t)。
不要用几十次累计布尔去逼近最终形状，否则会有累计误差、非流形和薄片。

三、算法链
A1 预处理：检查 M 封闭、流形、法线朝外；计算体积 Vol(M)、包围盒、质心。
A2 采样种子：在 M 内按密度 ρ 采样 N 个点；默认泊松盘，最小间距 r_min，避免薄片；可做 0–2 次 Lloyd 松弛 s_i ← centroid(V_i)，让块大小不过于极端。
A3 逐个求 V_i：从 M 开始，对每个 j ≠ i（实际只需 Delaunay 邻居）用 H_ij^- 裁剪，保留
f_ij(x) = (x - (s_i + s_j)/2) · n_ij ≤ 0，
其中 n_ij = (s_j - s_i) / ||s_j - s_i||。
A4 封口与拆连通分量：每次裁剪产生新的切面，补齐封口面，保证每块是封闭流形；若 V_i ∩ M 有多个不连通分量，按连通分量拆成多块，总块数可能大于 N。
A5 标记切面：原始外表面 is_cut = 0；由 H_ij 产生的新面 is_cut = 1；切面用略浅、略粗的材质。
A6 展示错位：每块沿其切面外法线的面积加权方向平移
d_i = ε · normalize( Σ_{f ∈ cut_i} A_f n_f )，
ε = 1–2 mm；对 d_i 截断，保证任意两块不互相穿插。块不旋转、不下落、不散开。
A7 切痕：第 k 刀对应切面 H_k；它在物体外表面的交线
C_k = ∂M ∩ H_k
是这一刀唯一可见的痕迹。沿 C_k 生成 0.5–1 mm 宽的窄带，在 0.15–0.3 s 内从入刀点向两侧展开；切面本身在块错开后露出。
d_i(t) = d_i · (1 - e^{-λt} cos(ωt))，
t 从该块被切开的时刻算起；λ ≈ 3–6 s^-1，ω ≈ 8–12 rad/s，产生 1–2 mm 的轻微回弹后停住。
A8 验收：
- 拼合态（d_i = 0）：∪V_i = M，任意两块内部不相交，ΣVol(V_i) = Vol(M)。
- 展示态（d_i ≠ 0）：任意两块不相交，缝宽 1–3 mm。
- 每块只属于一颗种子；默认凸物体时，每块内部恰好一颗种子。
- 所有切面为平面；无 NaN、无非流形、无零面积面。

四、参数与视觉影响
N：30→50，块变小、刀数变多；N 太大会产生薄片。
r_min：泊松盘最小间距；越大越均匀；越小越容易出现大小悬殊。
Lloyd 次数：0 自然但不均；1–2 更均匀；再多会失去自然碎裂感。
ε：1 mm 缝隙细；2 mm 缝隙明显；超过 3 mm 开始像散落。
λ、ω：控制回弹的快慢和次数；ω 太大像果冻，太小像没有回弹。
切痕宽：0.5 mm 细裂；1 mm 明显裂口。

五、刀不可见、不散落
刀不可见：场景里没有刀的对象，也没有刀的动画。
不散落：不做刚体、重力、碰撞、旋转。

六、边界与推广
非凸物体：V_i ∩ M 可能不连通，按连通分量拆块；总块数 ≥ N，每个分量仍属于同一颗种子。
缩放/各向异性：若要椭圆领地，把欧氏距离换成||x - s_i||_A = sqrt((x - s_i)^T A (x - s_i))，
切面仍是平面，只是平分面的法线变成 A(s_j - s_i)。
种子只在表面：只会得到表面裂纹，不会贯通成块；要贯通，种子必须分布在体积内。
种子分布：均匀随机会有扎堆和空洞；泊松盘更均匀；成簇分布会产生大小悬殊的块。
```
