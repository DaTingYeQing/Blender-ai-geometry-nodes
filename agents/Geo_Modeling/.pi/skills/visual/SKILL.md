# 视觉模型

## 第一步：理解与扩写，建立视觉模型
**目标**：把用户的一句话，扩写成一部能在脑海中播放的物理/动画短片。
1. **复述。** 用自己的话复述用户到底想要什么。分清三件事：哪些是明确要求，哪些是比喻，哪些是用户没说但效果必需的。
2. **找现实原型。** 问自己：这个效果在现实世界里对应什么？什么物体、什么力、什么运动？用现实中的东西定义它，而不是用「噪波」「场」「实例」这类术语。
3. **写成可播放的过程。** 按时间和因果顺序写：初始状态是什么 → 什么力或事件触发变化 → 中间形态怎么变 → 最终停在哪里；
4. **把模糊词变严谨。** 用户说「自然」「野」「高级」「有科技感」时，不要接受这个词，追问它具体指哪一种可见事实：是疏密不均，还是方向不齐，还是尺度有大有小？选当前效果真正用到的那一种，写进描述。
5. **补物理假设。** 用户没说的，补一个最合理的假设。
6. **收束成视觉模型。** 输出一段连续的、非技术语言的效果描述

**产出**：一段能让非专业读者在脑中播放的视觉模型，以及其中隐含的物理假设。

## 例子
```
以一块黄油为例；换成其他几何切法不变，只是形状不同。

你指定物体，它先在这块黄油内部撒下 30–50 颗看不见的“核”，像嵌在里面的芝麻。每颗核将来会占有一块领地：领地里的任意一点，离这颗核都比离别的核更近。这就是沃洛诺伊的样子——每块都是离自己那颗核最近的一片领地。

然后它开始一刀一刀地切，每一刀都不是随便落的。刀面一定落在两颗相邻的核的正中间，并且和两颗核的连线垂直：刀的一侧留给左边的核，另一侧留给右边的核。刀可能同时穿过好几块已经分开的黄油；穿过哪一块，哪一块就再裂成两块。每裂一次，就多一条平整的缝，缝的两面和相邻那块完全吻合，像拼图。切到每一块里只剩一颗核，就停。

核密的地方刀落得勤，块小；核稀的地方刀落得少，块大。最后，整块黄油变成大小不一的块，块与块之间留着均匀的细缝，像干裂的泥地。所有断面都是平的；几条断面相交的地方形成 Y 形或星形的接缝，不会出现圆弧形的裂口。每块的外表面仍然是原来黄油的外表面。

把块按原样推回去，能严丝合缝地拼回原来的方块，只剩发丝一样的缝。

隐含假设

物体是实心的闭合体；薄壳、空心、软体会改变“切”的表现。
每一刀都是平面直切，切在两颗相邻核的正中间、与连线垂直；“每块只剩一颗核”是停止条件。
块与块之间的细缝是展示时人为拉开的；几何上它们本来是无缝拼合的。
默认刀本身看不见，只有裂缝和错位。
默认切完只错开、不倒塌；如果要像打碎一样散落，视觉上会从“拼图”变成“碎片堆”。
假设：刀要不要可见、切完要不要散落？
```
